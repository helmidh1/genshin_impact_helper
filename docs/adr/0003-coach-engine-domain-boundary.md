# 0003: Coach Engine Domain Boundary and AI Strategy Seam

Rotation generation, Energy Recharge (ER) diagnostic benchmarks, buff bar timing, and heuristic equipment advice are extracted from the Gemini transport adapter (`src/lib/gemini.ts`) into a dedicated pure domain module: `src/lib/coach-engine.ts`.

1. **Pure Domain Isolation**:
   All Genshin Impact combat heuristics—including energy requirement formulas (adjusting for same-element battery counts, Raiden Shogun flat energy refunds, and Favonius procs), rotation sequencing (carry setup -> support snapshot buffs -> carry DPS window), Viridescent Venerer / burst duration timelines, and equipment advice synthesis—reside in `src/lib/coach-engine.ts`. This module contains zero I/O, zero network calls, and zero React hooks.

2. **AI Transport Adapter Seam**:
   `src/lib/gemini.ts` is strictly a transport adapter for the `@google/genai` Interactions API (`gemini-3.8-flash`). It owns prompt assembly, JSON schema definitions, and model interactions. When `GEMINI_API_KEY` is missing, invalid, or an API call fails, `gemini.ts` delegates fallback execution directly to `CoachEngine`.

3. **Deterministic Local-First Degradation**:
   The application remains 100% functional offline or without an AI API key. The fallback strategy and equipment advice generated by `CoachEngine` conform to the exact same TypeScript domain interfaces (`CoachStrategyResponse` and `EquipmentCoachQueryResponse`) as live Gemini responses.

4. **Unit Testability**:
   `CoachEngine` functions can be unit-tested deterministically and instantaneously with Vitest without mocking Google Gen AI clients, API keys, or HTTP transport layers.
